# CoastWatch – Design System

## 1. Design Theme
CoastWatch uses a clean, modern environmental design inspired by oceans and coastal ecosystems.

## 2. Colour Palette

| Colour | Hex Code | Usage |
|---|---|---|
| Ocean Blue | #123B50 | Primary colour |
| Teal | #159D91 | Secondary colour |
| Sea Mist | #E8F5F1 | Background |
| Amber | #F4B942 | Highlights |
| White | #FFFFFF | Cards and surfaces |
| Dark Grey | #253746 | Main text |

## 3. Typography
- Headings: Poppins
- Body text: Inter
- Buttons: Inter Semibold

## 4. Spacing
- Small: 8px
- Medium: 16px
- Large: 24px
- Section spacing: 48px
- Card padding: 20px

## 5. UI Components
- Primary and secondary buttons
- Navigation bar
- Statistics cards
- Pollution report cards
- Input fields and forms
- Status badges
- Dashboard sections

## 6. Status Colours
- Reported: Red
- In Progress: Amber
- Resolved: Green

## 7. Layout Guidelines
- Use a responsive grid system.
- Maintain consistent spacing.
- Use rounded cards and subtle shadows.
- Keep navigation simple.
- Ensure mobile and desktop compatibility.

## 8. Accessibility
- Use readable font sizes.
- Maintain sufficient colour contrast.
- Provide labels for form fields.
- Do not communicate status using colour alone.
